## Vinniebot Chess Engine

My Chess Engine is a project where you can play a game of chess against another person, or my amateur chess engine Vinniebot, or watch it play itself! I also finally learned pygame GUI so yeah you don't have to play in the terminal anymore! Have fun :)))
